■식별자

식별자(Identifier) : 변수, 함수, 클래스 등을 구별하기 위해 개발자가 부여한 이름

1) 식별자의 문법적 규칙 

 - 허용문자 : 알파벳, 숫자, 언더스코어( 언더바 _ ).
 - 시작문자 : 숫자로 시작할 수 없으며, 영문자와 언더스코어로만 시작할 수 있음
 - 예약어 금지 : 컴퓨팅 언어의 자체 구문 키워드(class, if, int 등등)는 식별자로 사용 불가

2) C/C++ 시스템 내부 예약 영역(언더스코어 주의사항)

코드 작성 시 언더스코어로 시작하는 식별자는 컴파일러 및 표준 라이브러리 전용 예약 영역과 충돌할 수 있음

 - 이중 언더스코어( _ _ ) : 모든 위치에서 C++ 컴파일러 전용 구문으로 예약됨.( __LINE__, __declspec 등)
 - 언더스코어 + 대문자(_A ~ _Z) : 전역 스코프 및 파일 스코프에서 예약됨 (_SIZE_T 등)
